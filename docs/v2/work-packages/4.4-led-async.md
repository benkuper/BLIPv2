# Work package 4.4: bounded asynchronous frames

`FramePipeline<BufferBytes, PoolSize>` stores aligned staging memory, slot state,
and queue metadata inline. Startup is the last point at which a driver may
allocate. Acquire, commit, service, completion, and stop perform no allocation.
Only one driver transaction is active; overload either rejects the newest frame
or drops the oldest queued frame. Counters expose submissions,
completions, failures, rejections, drops, queue high-water, deadline misses, and
maximum lateness.
