# Work package 4.6: production backend set

`select_backend` is independent of candidate registration order. It filters on
compiled state, broker/resource availability, qualification, protocol, lanes,
length, and staging budget. Forced unavailable or unqualified choices fail;
automatic choices report a stable reason for clocked, parallel, long-strip, or
short-strip policy.

Native asynchronous RMT/RMT-DMA and SPI-DMA adapters implement `OutputDriver`.
The SPI encoder expands one-wire bits as `0 -> 100`, `1 -> 110`. `OutputPort` and
`PortOutputDriver` provide the same ABI to target I2S/LCD, LCD_CAM, PARLIO, and
optional FastLED implementations. The target-neutral parallel encoder transposes
up to sixteen lane payloads into deterministic three-phase bit-plane samples.
Physical qualification remains a separate, explicit capability bit as required
by ADR-0007.
