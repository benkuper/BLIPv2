# Work package 4.3: linear-light color pipeline

`ColorTransform` applies a signed Q16.16 RGB matrix, four channel calibration
gains, and global brightness while values remain linear. Only then does the
pipeline apply linear, sRGB, or gamma-2.2 transfer and configurable RGB/RGBW
ordering. Eight- and sixteen-bit encoding share the same transform. Host golden
vectors cover endpoints, sRGB mid-grey, ordering, and protocol integration.
