# Work package 1.3: typed descriptors

## Scope

Component descriptors define versioned parameters, actions, events, metadata,
diagnostics, resource claims, settings schemas, disable policy, and service
dependencies. Values and fields use explicit types. Dynamic controls are added
through an atomic fixed-capacity registry transaction rather than heap-backed
runtime mutation.

The JSON writer serializes a complete descriptor into caller-owned storage. It
returns a typed overflow error when the buffer is too small and does not throw or
allocate.

## Acceptance evidence

The synthetic descriptor host test exercises all public control categories,
checks the versioned machine-readable output, verifies bounded serialization,
and checks atomic dynamic-control extension including duplicate and capacity
failures.

## Compatibility, rollback, and migration

Schema version `1` is new V2 metadata; it does not replace the V1 OSCQuery tree
or settings format. Later adapters may transform registry data into legacy
views. Removing the descriptor and serializer files rolls back this package,
with no persisted-state migration.
