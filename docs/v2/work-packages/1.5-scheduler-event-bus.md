# Work package 1.5: scheduler and event bus

## Scope

The monotonic scheduler has fixed-capacity queues for real-time, control, I/O,
and background task classes. Every task carries an owner, deadline, execution
budget, cancellation token, and explicit overflow policy: reject, drop-oldest,
coalesce, or fault. Queue and execution metrics saturate rather than wrap. A
32-bit tick extender preserves monotonic time across wraparound.

The typed event bus uses fixed-capacity subscriber lists and queues, requires a
declared dispatch context, makes overflow visible, rejects recursive dispatch,
and invalidates queued work when a producer generation stops.

## Acceptance evidence

Host tests cover queue ordering, all overflow policies, deadline/budget metrics,
cancellation and owner cancellation, tick wraparound, event delivery,
coalescing, stale generation removal, recursive dispatch rejection, and metric
saturation. Firmware constructs the scheduler before registry start and emits a
readiness marker only after the core composition succeeds.

## Compatibility, rollback, and migration

This package adds internal V2 execution contracts only. It changes no V1 public
path or wire format. Removing the scheduler/event headers and their application
wiring rolls it back; no persisted-state migration is required.
