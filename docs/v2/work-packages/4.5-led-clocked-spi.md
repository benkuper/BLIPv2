# Work package 4.5: clocked SPI strips

The protocol boundary produces APA102/SK9822 start, BGR pixel, brightness, and
end frames plus the HD108 v1.2 128-bit start and 64-bit-per-pixel format with
per-channel current fields and 16-bit RGB. Clock limits and physical period are
reported through the ABI. `EspSpiDmaOutputDriver` queues one DMA transaction and
polls completion without blocking the render task; it rejects non-DMA-capable or
oversized buffers. Host loopback goldens verify byte layout.

The HD108 encoder appends at least eight zero bytes after the pixel frames,
matching the Creators Ball V2's earlier NeoPixelBus driver. The firmware uses
SPI2 at 4 MHz for the fixed 36-pixel onboard chain. The output remains
unqualified until a hardware color test and clock/data capture are recorded.
