# Work package 6.6: Script declaration foundation

- Date: 2026-10-08
- Status: Portable declaration contract qualified; live controls pending
- Contract: [ADR-0015](../adr/0015-wasm-script-control-declarations.md)
- Evidence: [script declarations](../evidence/wasm/2026-10-08-script-declarations.json)

The optional `blip.controls.v1` custom section declares up to 16 typed
parameters/actions/events, with four required fields per action/event. The
decoder validates all input before replacing the owned schema. It copies all
text into a bounded 2 KiB arena, preserves numeric bits and projects existing
core descriptor types. No guest code executes and no input pointer survives.

Tests began with an unimplemented API/link failure. All 25 host suites now pass.
The 12 declaration cases cover four scalar types/access, bounds, full i64
precision, signed zero, UTF-8/embedded NUL defaults, overwritten input and schema
copies, every incomplete section prefix, framing/version/name errors, duplicate
controls/fields, invalid metadata, exact arena/byte limits and projection failure
atomicity. Wasmtime 36.0.0 independently validates the repeated fixture's Wasm
framing.

The independent ESP-IDF qualifier compiles these same cases and the exact
portable source on all three chip families. Each passes the 12 cases and 1,000
additional parses into a fixed owner, with flat warmed internal heap:

| Board | Target | Heap throughout repeat | Largest simple-fixture parse | Qualification stack headroom |
| --- | --- | ---: | ---: | ---: |
| XIAO | C6 | 449,508 B | 51 us | 8,500 B |
| HUZZAH32 | ESP32 | 270,940 B | 91 us | 8,324 B |
| M5Dial | S3 | 370,812 B | 43 us | 8,028 B |

The owned schema is **3,464 bytes** on all three embedded targets. The parser's
largest individual compiler frame is 480 bytes on C6 and 448 bytes on ESP32/S3;
these are per-function reports, not complete call-chain measurements. The
20 KiB qualification stack accommodates allocating host fixtures and multiple
schema copies. Production must reserve the schema outside its 8 KiB worker
stack. Repeated timing uses one boolean control, not a worst-case schema or
deadline guarantee.

Matching bootloader/partition/application images were flashed, and M5Dial used
stub-assisted `run`. A C6 app-only attempt produced boot output but no qualifier
completion; the matching full image passed. The runner requires the generated
layout, records verified MAC/artifact hashes and rejects incomplete results.
Validated qualifier firmware remains on these three test boards. The PC Wi-Fi
connection was unchanged; no firmware restoration was requested or performed.

These small qualification images do not run an interpreter or production
services. Their sizes are 157,056 B (C6), 157,232 B (ESP32) and 172,272 B (S3),
not production feature costs. Production does not yet instantiate the schema or
consume the custom section. The previous seven-profile provider build evidence
remains its own checkpoint; the production matrix will be renewed when live
controls are integrated.
