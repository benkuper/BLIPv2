# Work package 4.2: deterministic compositor

`Compositor` contains exactly four slots. Their priority is fixed as `stream`,
`playback`, `script`, and `system`, independent of registration order. Replace,
straight-alpha over, saturating add, and multiply operate in 16-bit linear light;
layer opacity participates in every blend. Disabled slots cost no per-frame
allocation and mismatched surface sizes fail closed.

The Creators Ball V2 worker now feeds its solid system layer and DDP stream
layer through this compositor before encoding the HD108 frame. Host tests and
COM10 frame completion checks passed. Playback and script producers, plus
runtime compositor integration on the other boards, remain open.
