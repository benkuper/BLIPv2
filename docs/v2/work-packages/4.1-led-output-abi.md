# Work package 4.1: LED output ABI

`PixelSurface` and `ConstPixelSurface` carry bounded linear-light pixels and an
explicit lane layout. `OutputDriver` is the sole submission boundary. Its
capability record advertises supported protocols and formats, lane and clock
limits, reset time, calculated physical frame period, staging memory, alignment,
buffering, DMA, synchronization, qualification evidence, and claimed resources.

Configuration is validated before a port starts. Staging arithmetic saturates
on overflow, and unsupported format, protocol, clock, lane, and length requests
fail before touching hardware. Host coverage is in `blip_led_m4_tests`.
