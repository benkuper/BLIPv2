# Work package 3.7: Simple/Advanced browser foundation

- Date: 2026-10-08
- Status: graphical interface foundation qualified; wider 3.7 and self-updates open
- Contract: [ADR-0018](../adr/0018-device-web-presentation.md)
- Evidence: [three-family browser trials](../evidence/web/2026-10-08-simple-advanced.json)

The device now serves Simple by default: declared main controls, switches,
sliders, recent real-value graphs, meters and sensor/status readings. Advanced
renders all published controls and the complete existing pin/reservation view,
with topic navigation and search. Component metadata drives presentation;
leased guest declarations appear automatically. The app polls every three
seconds while visible, backs off on failure, updates existing values, preserves
focused drafts and rebuilds editors when shape/schema generation changes.

The web bundle is independently versioned **0.2.0**, **22,116 bytes**, with ten
assets. No external fonts/scripts are required. Four browser failures were fixed
and preserved in the evidence: the setup AP intercepted home; browser ESM
parallelism exceeded four HTTP sessions; normal Accept exceeded 128 bytes;
and native Window.fetch was called with a DeviceClient receiver. The home page
now owns station/AP navigation, `/setup` retains recovery, module startup is
sequential, Accept parsing is bounded at 256 bytes and fetch is correctly bound.

All **28 host suites**, **25 web tests**, seven production builds and the
WASM-disabled build pass. Microsoft Edge **154.0.4258.62**, Playwright **1.62.1**
and Node **26.5.0** ran **45 browser checks** against the actual device-served
bundle on three boards. Each trial verified the installed bundle CRC/version,
Simple defaults, all published Advanced controls, keyboard navigation, topics,
search, pin visibility, actual polled graphs, 390-pixel phone layout without
horizontal overflow, dynamic load/unload refresh and retained focused drafts.
Screenshots were captured and desktop/phone layouts inspected. No browser
exceptions occurred. Snapshot/image/checker/flash/screenshot hashes are recorded.
