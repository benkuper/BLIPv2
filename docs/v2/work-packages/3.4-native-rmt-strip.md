# Work package 3.4: qualified native RMT strip vertical slice

- **Status:** production component and three-target serial/web/OSC HIL complete;
  external-strip and logic-analyzer acceptance remains open.
- **Depends on:** work packages 1.4, 1.5, and 2.7; ADR-0007.
- **Scope:** a single WS2812/SK6812 strip, native ESP-IDF RMT output, persisted
  registry controls, host timing/order goldens, and three-target physical HIL.

## Qualification boundary

[ADR-0007](../adr/0007-led-transport-qualification.md) selects ordinary RMT
only for the Milestone 3 single-strip slice. The disposable harness completed
all 115 expected rows on ESP32, ESP32-S3, and ESP32-C6 and restored the original
flash range after every run. Multiline and parallel engines remain blocked on
an external capture fixture and are not production backends.

## Required component contract

The component is `blip.output.strip0` and provides `output.pixel-strip`. Its
descriptor exposes enabled state, GPIO, protocol, pixel count, global RGBW
values, brightness, applied-frame count, failed-frame count, last completion
time, and backend identity. Configuration is versioned and persisted; color
writes schedule output without allocating or blocking the network callback on
the wire period.

The portable encoder/model owns channel order and protocol timing. ESP-IDF RMT
is an adapter behind that boundary. WS2812 emits GRB data and SK6812 emits GRBW;
host goldens cover walking bits, brightness, maximum length, invalid settings,
and exact tick durations. The RMT channel is preallocated at start and remains
single-lane.

## Acceptance evidence

- Host golden and lifecycle tests pass with exceptions/RTTI disabled.
- Clean ESP32, ESP32-S3, and ESP32-C6 builds pass.
- Web and OSC write the same registry parameters on each reference target.
- Settings survive restart, and failed configuration leaves the last valid
  output/settings generation active.

The first, second, third, and sixth rows passed on 2026-08-15. The repeatable
record is
[`2026-08-15-native-rmt-hil.json`](../evidence/led-transport/2026-08-15-native-rmt-hil.json).
The XIAO C6 record also proves that its persisted antenna selector is `onboard`
(`1`), matching the attached chip-antenna boards. The M5Dial run used its
board-integrated RGB LED pin, GPIO21.

Still required for full physical acceptance:

- A real common strip on each target reproduces a walking RGB(W) sequence.
- External capture decodes the expected bytes and pulse/reset timing.

Those capture rows remain open until the common strip and analyzer fixture are
attached; no visual or timing result is inferred from successful RMT completion.
